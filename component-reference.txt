COMPONENT REFERENCE - Fundamental AWS (Astro + MDX)
================================================================================

Ground truth seluruh komponen yang boleh di-import dari "@components" di dalam
modul .mdx. Lampirkan file ini ke Project ChatGPT bersama ai-instructions.md
supaya model menulis import, prop, dan slot PERSIS sesuai sumber (anti-halusinasi).

Aturan singkat yang paling sering salah:
- Import HANYA dari "@components": Section, Box, Steps, Step, Recap, CardGrid,
  Card, Figure, Chip, Hero, Compare. Tidak ada komponen lain. Jangan mengarang.
- Hero: judul lewat prop `title` (HTML, set:html). JANGAN tulis <h1> di MDX.
- Chip: HANYA di slot meta Hero; `icon` dari 8 nama sah saja (lihat Chip.astro).
- Box: 4 varian sah (tip|analogy|warn|exam); `label` boleh HTML; `icon` emoji.
- Section: `title`/`sub` boleh HTML; <h2> milik Section (sub-judul pakai <h3>/<h4>).
- Figure: bungkus komponen SVG; caption opsional lewat slot name="caption".
- Tiap blok/komponen berteks ditulis SATU baris (lihat ai-instructions.md).

// Hero modul. eyebrow di atas, judul (h1), lalu slot (lede), lalu slot "meta" (chips).
// PENTING: `title` di-render di .astro via set:html — JANGAN tulis <h1> multi-baris di
// dalam MDX, karena parser MDX akan membungkus isinya ke <p> (judul jadi mengecil 19px).
interface Props {
  eyebrow?: string;
  title?: string; // HTML judul, mis. 'Amazon <em>EC2</em><br />Elastic Compute Cloud'
}
const { eyebrow, title } = Astro.props;
---
<div class="hero">
  {eyebrow && <div class="eyebrow" set:html={eyebrow} />}
  {title && <h1 set:html={title} />}
  <slot />
  <div class="hero-meta">
    <slot name="meta" />
  </div>
</div>

PEMAKAIAN (MDX):
<Hero eyebrow="Modul &middot; Storage" title="Amazon <em>S3</em><br />Simple Storage Service">
  <p>Satu kalimat pembuka dalam satu baris.</p>
  <Fragment slot="meta">
    <Chip icon="target">Target: <b>CLF-C02</b></Chip>
    <Chip icon="clock">~60 menit baca</Chip>
  </Fragment>
</Hero>

// Perbandingan dua sisi yang sering tertukar (mis. CapEx vs OpEx, Scalability vs
// Elasticity, security OF vs IN the cloud). Dua panel berdampingan dengan badge "vs"
// di tengah. Isi tiap sisi lewat slot "a" dan "b"; label & nada warna lewat prop.
// Gaya .compare/.cmp-* ada di globals.css (area REVAMP 2026), reaktif tema.
interface Props {
  aLabel: string;                                  // judul panel kiri (boleh HTML)
  bLabel: string;                                  // judul panel kanan (boleh HTML)
  aTone?: 'muted' | 'blue' | 'teal' | 'red' | 'violet';  // warna garis-atas kiri (default muted)
  bTone?: 'muted' | 'blue' | 'teal' | 'red' | 'violet';  // warna garis-atas kanan (default blue)
  vs?: string;                                     // teks badge tengah (default "vs")
}
const { aLabel, bLabel, aTone = 'muted', bTone = 'blue', vs = 'vs' } = Astro.props;
---
<div class="compare">
  <div class={`cmp-side cmp-${aTone}`}>
    <div class="cmp-label" set:html={aLabel} />
    <div class="cmp-body"><slot name="a" /></div>
  </div>
  <div class="cmp-vs" aria-hidden="true">{vs}</div>
  <div class={`cmp-side cmp-${bTone}`}>
    <div class="cmp-label" set:html={bLabel} />
    <div class="cmp-body"><slot name="b" /></div>
  </div>
</div>

PEMAKAIAN (MDX) — isi slot "a"/"b" dengan <p> atau <ul><li>; tone dari 5 nama sah:
<Compare aLabel="CapEx" bLabel="OpEx" aTone="muted" bTone="blue">
  <Fragment slot="a"><ul><li>Modal besar di awal.</li></ul></Fragment>
  <Fragment slot="b"><ul><li>Bayar sesuai pemakaian.</li></ul></Fragment>
</Compare>
